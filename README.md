# GEX PRO track record

Written by the hosted site's workflow. `sessions/YYYY-MM-DD_MARKET.json` holds each session's plan (the
levels from the last calculation timestamped before the 09:30 ET open) and, after the close, its grade.
Git history shows when each plan and grade was written. Rules: `trackrecord/score.py` on `main`.
Sessions 2026-10-21 to 2026-10-23 were rebuilt on 2026-10-23 from snapshots saved before each open.
